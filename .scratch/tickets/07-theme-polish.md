## What to build

Polish the app into a cohesive, dark-first study workspace. Add a light/dark theme toggle that persists the student's preference. Apply consistent styling across all tabs — slate background, green accent for success states, amber for flashcard highlights. Add empty states for when no workspace is selected, no documents uploaded, no flashcards/quizzes/summaries generated. Update the README with setup instructions, feature overview, and screenshots.

## Acceptance criteria

- [ ] Dark theme applied by default across the entire app
- [ ] Light/dark toggle in the header persists the student's preference
- [ ] Consistent color palette: slate background, green accent for success, amber for flashcard highlights
- [ ] Empty state messaging when no workspace is selected
- [ ] Empty state messaging in each tab when there is no data yet (no documents, no flashcards, etc.)
- [ ] README updated with project description, setup/run instructions, feature overview, and tech stack
