# StudyMate

An AI-powered study companion that helps students organize materials, ask grounded questions, and actively learn through flashcards, quizzes, and summaries.

## Language

**Workspace**:
A named container representing a subject or course (e.g., "CS101", "Biology Midterm") that holds documents, chat sessions, flashcards, quizzes, and summaries. Each workspace has its own isolated vector collection.
_Avoid_: Project, folder, notebook

**Document**:
An uploaded file (PDF, DOCX, TXT, or MD) belonging to a workspace, with extracted text and page-level metadata stored for retrieval.
_Avoid_: File, upload, attachment

**Chunk**:
A segment of a document's extracted text (~250 words) with page number metadata, embedded as a vector and stored in the workspace's ChromaDB collection.
_Avoid_: Fragment, segment, passage

**Citation**:
An inline numbered reference (e.g., [1][2]) in an AI answer linking to a specific page number and text snippet from a source document, displayed in a collapsible Sources panel.
_Avoid_: Reference, footnote, source link

**Flashcard**:
A question/answer pair generated by the LLM from workspace documents. Reviewed via flip-and-rate (Got it / Missed it) with progress tracking.
_Avoid_: Card, recall card

**Quiz**:
A set of multiple-choice questions generated by the LLM from workspace documents, with configurable question count and difficulty (Easy / Medium / Hard). Results include score, correct answers, explanations, and citations.
_Avoid_: Test, exam, assessment

**Summary**:
A structured Markdown study guide generated per document, containing key concepts, definitions, and important points. Displayed as a rendered card in the Summary Notes tab.
_Avoid_: Notes, overview, outline

**Study Set**:
The collective flashcards, quizzes, and summaries generated for a workspace. Created on-demand, not automatically on upload.
_Avoid_: Learning materials, study pack
